# Visor BIM · Las Heras 1832

Sitio estático (GitHub Pages) de Korn Desarrolla · Lifestyle Las Heras 1832, Recoleta.
Duplicado del visor de Ortega y Gasset 1957 adaptado a esta obra.

- `index.html` — Inicio, Visor 3D (IFC), Novedades y Brochure.
- `assets/` — logos, portada (render pileta + SUM, brochure pág. 11) y brochure PDF.
- `models/model.ifc` — modelo IFC de la obra (pendiente).
- `novedades/` — informes mensuales de avance de obra (ver `novedades/README.md`).

Todas las rutas son relativas: el contenido de esta carpeta funciona tanto en la raíz de un repo propio como en una subcarpeta.
