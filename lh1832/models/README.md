# Modelo 3D

Subí acá el IFC de Las Heras 1832 con el nombre `model.ifc`.
El visor lo carga automáticamente al abrir la pestaña **Visor 3D**.
Mientras no esté, el visor muestra "El modelo 3D de Las Heras 1832 todavía no está publicado."

Los elementos con la propiedad `Certificated` = YES/TRUE se pintan en verde.
